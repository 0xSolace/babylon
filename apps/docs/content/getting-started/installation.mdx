# Installation

Get Babylon running on your local machine in minutes.

## Requirements

| Requirement | Version | Notes |
|-------------|---------|-------|
| **Bun** | 1.1+ | Recommended runtime ([install](https://bun.sh)) |
| **Node.js** | 20.9+ | Alternative to Bun (required by Next.js 16) |
| **Git** | Latest | Version control |
| **Jeju** | Latest | Decentralized infrastructure (see below) |

**Tech Stack:** Next.js 16, React 19, TypeScript 5.9, Drizzle ORM, OAuth3 Auth, Tailwind CSS 4, Viem/Wagmi, CovenantSQL

## Quick Setup

### 1. Start Jeju (Decentralized Infrastructure)

Babylon runs on Jeju's decentralized stack. Start the devnet first:

```bash
# From the Jeju monorepo root
bun run dev
```

This starts:
- CovenantSQL (decentralized database)
- Jeju Cache (decentralized cache)
- Jeju Storage (IPFS-backed storage)
- Jeju Compute (LLM inference marketplace)
- OAuth3 (decentralized auth)
- Local blockchain node

### 2. Clone and Install

```bash
cd vendor/babylon
bun install
```

### 3. Configure Environment

```bash
cp .env.example .env.local
```

The default `.env.local` is pre-configured for local Jeju devnet:

```env
# Jeju Decentralized Services (pre-configured for devnet)
CQL_BLOCK_PRODUCER_ENDPOINT="http://localhost:15151"
JEJU_CACHE_SERVICE_URL="http://localhost:8080/cache"
JEJU_STORAGE_SERVICE_URL="http://localhost:8080/storage"
JEJU_COMPUTE_API_URL="http://localhost:8080/compute"

# Blockchain (Anvil/Hardhat)
RPC_URL="http://localhost:8545"
CHAIN_ID="31337"

# OAuth3 Authentication
OAUTH3_ISSUER_URL="http://localhost:8080/oauth3"
```

### 4. Setup Database

CovenantSQL is automatically provisioned when Jeju starts. Push the schema:

```bash
bun run db:push
bun run db:seed
```

### 5. Start Development

```bash
bun run dev:web
```

Visit `http://localhost:3000` - content generates automatically!

## Verify Installation

```bash
bun run db:status   # Check database
bun run typecheck   # Check types
bun run lint        # Check linting
```

## Troubleshooting

<details>
<summary>Jeju Devnet Not Starting</summary>

```bash
# From Jeju monorepo root
bun run dev:clean   # Clean start
```

</details>

<details>
<summary>CQL Connection Error</summary>

```bash
curl http://localhost:15151/health   # Check CQL
curl http://localhost:8080/health    # Check Jeju Gateway
```

</details>

<details>
<summary>Port Already in Use</summary>

```bash
lsof -i :3000                           # Find process
bun run dev -- -p 3001                  # Use different port
```

</details>

<details>
<summary>Database Schema Issues</summary>

```bash
bun run db:push                         # Reset schema
bun run db:generate && bun run db:migrate  # Regenerate
```

</details>
